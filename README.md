# Student Performance Analysis

## 📌 Project Overview

Student Performance Analysis is a Python-based project developed to analyze and visualize student academic performance data. The project includes data processing, validation, analysis, and an interactive student dashboard.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Excel
* Data Analysis
* Data Visualization

## 📂 Project Structure

```text
Student-Performance-Analysis/
│
├── analysis.py
├── create_dataset.py
├── data_validator.py
├── main.py
├── student_dashboard.py
├── student_data.xlsx
└── README.md
```

## ✨ Features

* Student data analysis
* Data cleaning and validation
* Academic performance analysis
* Data visualization
* Student performance dashboard
* Excel dataset handling

## 📊 Dataset

The project uses `student_data.xlsx` as the dataset containing student academic performance information.

## 🚀 How to Run

1. Clone this repository.
2. Install the required Python libraries:

```bash
pip install pandas matplotlib openpyxl
```

3. Run the main Python file:

```bash
python main.py
```

4. Open the student dashboard using:

```bash
python student_dashboard.py
```

## 🎯 Project Objective

The main objective of this project is to analyze student academic performance and present meaningful insights through data analysis and visualization.
